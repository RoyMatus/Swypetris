# Optional ticket execution journal

Use `Record-EpicWork.ps1` only when detailed observed phase timing serves a concrete analysis. The ignored `app/build/verification/epic-E/work.jsonl` or `ticket-N/work.jsonl` holds UTC Start/Stop events. One owner writes it; stop an active interval before leaving or waiting. Never reconstruct missing time from commits. Keep secrets and private data out of notes.

At completion, `Get-DevelopmentTicketTime` counts completed Implementation, Review, ReleasePreparation and Rework intervals as a measured lower bound. `Complete` requires independent review of capture coverage; missing work is Partial or Unknown. Runner JSON supplies actual check runtime independently. Do not add phase, runner or overlapping job durations.

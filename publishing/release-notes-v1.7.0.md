# Swypetris 1.7.0

- Connected block materials now use the approved final artwork across all twelve themes.
- Each theme has its own drop and line-clear sounds, including when a random theme is chosen or a saved game is resumed.
- The Hold preview shows its blocks at the same opacity as the active piece, including after Hold has been used.

This release includes the gameplay and visual improvements from 1.6.0. Existing game data is preserved when updating from 1.6.0.

# Swypetris 1.5.1

- Victory and Absolute Victory now use pixel sparks that explode, fall with fading trails and extinguish. The static victory postcard shares the new style.
- Results uses clearer best-result and archived-record labels; history cards retain their difficulty without internal rules-version text. Existing results remain intact.
- The starting-level explanation remains readable on narrow screens and at larger font sizes.
- Regression selection now includes the starting-level setting. Portrait settings fixtures, the complete test inventory and English/Russian behavior documentation have been reconciled.

Android 7.0+; portrait play. Original application signing identity preserved. The
universal APK, update metadata and SHA-256 checksums are published through GitHub
Releases. This release does not submit the app to RuStore or claim moderation
approval. Builds and verification run locally on Windows; the local Sonar scanner
uses the existing SonarQube Cloud Quality Gate.

[Motion clips, phase frames and measured limitations](https://github.com/RoyMatus/Swypetris/blob/251af6c66a92da7c9cac7f76fba6ca2ac06fedbb/publishing/evidence/issue-248/README.md)
are available for the firework change. No physical-device FPS, battery savings,
human listening or aesthetic acceptance claim is made from emulator tests.

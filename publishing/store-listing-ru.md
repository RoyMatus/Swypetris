# Черновик карточки Swypetris 1.6.0 (не подтверждает состояние консоли)

**Название:** Swypetris

**Краткое описание:** Головоломка с жестами, музыкой и 12 расцветками. Играйте без сети.

## Полное описание

Собирайте горизонтальные линии, управляйте падающими фигурами жестами и побейте собственный рекорд!

Swypetris — бесплатная игра для Android без рекламы, покупок и регистрации. Играть можно без интернета; сеть используется для проверки обновлений.

- Управление жестами: перемещайте, поворачивайте и быстро опускайте фигуры прямо на поле.
- Двенадцать расцветок, включая классическую, Monokai, Dracula, Nord и две светлые темы.
- Фактурные блоки, тематические фоны поля и анимированная заставка. Можно выбрать собственное изображение для фона.
- Восемь инструментальных ретро-аранжировок. Выбирайте одну мелодию или слушайте весь плейлист: каждый круг открывают «Коробейники».
- Зарабатывайте фрукты за очки. Соберите все восемь, получите поздравление и начните следующий круг с сохранением счёта и скорости.
- Личная история результатов и рекорды на устройстве.
- Независимые настройки музыки, звуков и вибрации. Подсказки показывают место падения и следующую фигуру.

Игра рассчитана на портретный экран Android 7.0 и новее. Все возможности доступны бесплатно.

## Что нового

Обновлены материалы блоков и фоны всех 12 расцветок. Фрукты выстроены в две колонки со счётчиками, цифры счёта на светлых темах стали чёрными без подложки. Музыка продолжает играть при открытии списка мелодий. Скорость падения после выбранного начального уровня нарастает плавнее.

При первом запуске этой версии прежние рекорды, история результатов и сохранённая партия сбрасываются один раз из-за изменения баланса. Настройки, имя игрока и выбранный фон сохраняются; новые результаты и партии сохраняются как обычно.

## Поля консоли

- Тип: игра. Категория: головоломки.
- Цена: бесплатно. Рекламы и встроенных покупок нет.
- Разработчик: Roy Matus. Email: piligrim18@gmail.com. Сайт: https://itoltec.ru/.
- Идентификатор: `ru.itoltec.swypetris`; версия `1.6.0`, код `24`.
- Политика: загрузить `privacy.html` на собственный сайт и вставить фактическую публичную HTTPS-ссылку. Подготовленный файл ещё не опубликован.
- Возрастной рейтинг определится по заполненной анкете магазина. Целевую аудиторию указывает владелец аккаунта; рейтинг и аудитория — разные поля, автоматически назначать их по этой памятке нельзя.
- Объявление о безопасности данных: приложение не отправляет данные разработчику, не содержит рекламы и собственной аналитики игровых действий. Для установок из RuStore используется SDK обновлений RuStore 10.5.1 с техническими модулями analytics/metrics; прямые APK проверяют GitHub Releases. Сведения об SDK и выбранной пользователем передаче открыток раскрыты в политике конфиденциальности. Имя игрока, история и настройки хранятся локально; Android может включать их в системную резервную копию. Перед отправкой декларации сверить ответы с актуальными определениями магазина.
- Доступ для проверяющих: все функции доступны без аккаунта, пароля и платежей.

# Swypetris 1.4.1

- Download and install signed APK updates inside Swypetris, with progress, cancellation, and Android permission/confirmation handling.
- Enable automatic downloads and installation after explicit first consent; installation waits for the main menu and preserves the saved game, settings, and history.
- Validate update metadata, SHA-256, package/version, and signing certificates before installation. RuStore installations continue to use the RuStore update SDK.
- Include the completed Epic #92 gameplay changes: standard Marathon gravity and progression, lock delay with bounded resets, Hold, SRS rotations in both directions, scoring, a seven-bag queue, and an always-visible Next preview.

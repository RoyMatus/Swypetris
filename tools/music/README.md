# Нотные источники и собственные записи

В APK включены только собственные синтезированные Ogg Vorbis, а не чужие аудиозаписи.
Нотные данные и источники сохраняются рядом с генератором.

| Калинка | Иван Ларионов; https://www.freesheetmusic.net/music/worldfolk/russian/kalinka.pdf | Полная мелодия куплета и припева, нотный MIDI без автоаккомпанемента |
| Камаринская | Народная; https://www.freesheetmusic.net/music/worldfolk/russian/kamarynska.pdf | Вся записанная плясовая тема с повторами и вариантами, не фантазия Глинки |
| Барыня | Народная; https://www.freesheetmusic.net/music/worldfolk/russian/barinya.pdf | Оба колена народной темы с повторами |

«PDMX: A Large-Scale Public Domain MusicXML Dataset for Symbolic Music Processing», ICASSP 2025.
https://github.com/pnlong/PDMX — опубликованный корпус public-domain нот.

Названия авторов нотных редакций сохранены; автоаккомпанемент ABC не копируется.

## Генерация одной командой

`pwsh -File tools/Generate-Music.ps1 -Python <python.exe>`

Нужны Python 3.11+ с numpy 2.3.5 и PowerShell 7.
`tools/music/Setup-Music.ps1 -Python <python.exe>` устанавливает локальные зависимости и закреплённый кодировщик.
Для повторного извлечения нот из сохранённых источников: `python tools/music/build_scores.py` (mido 1.3.3).
В обычной генерации используются уже сохранённые, проверенные `scores/*.json`.

FFmpeg 8.1.2 essentials build:
https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-8.1.2-essentials_build.zip
SHA256: DB580001CAA24AC104C8CB856CD113A87B0A443F7BDF47D8C12B1D740584A2EC
Кодировщик — libvorbis, качество 4, постоянный serial 42, без временных метаданных.
FFmpeg используется только как инструмент сборки и не включается в APK.
Его лицензия и сведения об исходниках входят в архив дистрибутива: https://ffmpeg.org/legal.html

Народные мелодии звучат целиком в каждом проведении: вступление, вариации с передачей мелодии между инструментами,
инструментальная середина, каденция. Для каждой темы собственная гармонизация, бас и арпеджио.
Темп постоянный, не зависит от скорости игры. Фея Драже — 90 BPM, Трепак — 144 BPM.
Готовые записи имеют естественную длину: Трепак не растянут до трёх минут.

`app/build/reports/audio` содержит исходные WAV, 30-секундные образцы,
`playlist-report.json` (форма, длительности, хеши) и `decoded-validation.json` (пики после Vorbis).
Проверка: `pwsh -File tools/Check-Music.ps1 -Python <python.exe>`.


## Насыщенная Sega-аранжировка

Все восемь записей создаёт `render_playlist.py`, включая «Коробейники». Старый C#-генератор вызывается только для прежних фанфар (`GenerateFanfare`). Нотный JSON «Коробейников» воспроизводится из `melody.txt` общей командой извлечения нот.

Для шести народных тем в `PROFILES` записаны собственные гармонические карты, ведущие тембры, аккордовые инструменты и характер ритма. Для «Во саду ли, в огороде» сопровождение и заключение согласованы с ми-минорным окончанием мелодии. Автоматический выбор одного аккорда по частоте нот удалён. Основная мелодия остаётся полной; через каждые восемь четвертей меняется ведущий инструмент, между фразами звучат ответы электропиано. Бас использует синкопы, квинты, октавы и переходы к следующему корню. Аккорды короткие, без непрерывной подложки. Полные партитуры Чайковского сохранены; группам назначены разные тембры, динамика и изменяемый ритм.

Собственный синтез: FM-духовые, язычковый лид, электропиано, стеклянный щипок, FM-гитара, орган, короткие струнные, бас, арпеджио и колокольчики. Ударные: бочка, малый, хлопок, закрытый/открытый хэт, высокий/низкий том и тарелка. Сбивки через четыре двухдольных такта; разреженная инструментальная середина отделяет повторения.

Баланс: RMS не выше 0.13, линейное ограничение усиления по пику 0.76, без жёсткого клиппинга. Проверка после Vorbis требует разброс RMS между песнями менее 3 дБ, отсутствия отмены каналов в моно, плавного конца и не менее 12 использованных тембров/видов перкуссии. Состав инструментов, гармонии и разделы записаны в `playlist-report.json`. Эти измерения проверяют техническое качество; художественное впечатление оценивается при прослушивании.

Приложение позволяет слушать одну песню или случайную очередь без повторов в игре и настройках. Между песнями и повторами 1,5 секунды. Режим «Выключена» отключает и фанфары.

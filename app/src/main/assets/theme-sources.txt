# Расцветки

Палитры адаптированы к фигурам и интерфейсу Swypetris; это не полные реализации тем редакторов.
Фон, основные оттенки и акценты взяты из опубликованных палитр. Отсутствующие синие оттенки
Monokai/Dracula добавлены для различимости семи фигур; приглушённый текст и светлые акценты
адаптированы для читаемости. Логотип и фруктовые спрайты сохраняют свои цвета.

- Классическая: I cyan, O yellow, T purple, S green, Z red, J blue, L orange.
  https://cdn.steamstatic.com/steam/apps/1259790/manuals/tenpex_WM_210216_Steam_en.pdf
- Monokai: https://github.com/microsoft/vscode/tree/main/extensions/theme-monokai — MIT, Microsoft.
- Gruvbox Dark: https://github.com/morhetz/gruvbox — morhetz; заимствованы значения опубликованной палитры, код темы не копировался.
- VS Code Dark+: https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults — MIT, Microsoft.
- Dracula: https://github.com/dracula/dracula-theme — MIT, Dracula Theme.
- Nord: https://github.com/nordtheme/nord — MIT, Arctic Ice Studio / Sven Greb.
- Solarized Light: https://github.com/altercation/solarized — MIT, Ethan Schoonover.
- GitHub Light: https://github.com/primer/github-vscode-theme — MIT, GitHub.
- Tokyo Night: https://github.com/folke/tokyonight.nvim — Apache-2.0, folke.
- Catppuccin Mocha: https://github.com/catppuccin/catppuccin — MIT, Catppuccin.

Полные предоставленные проектами лицензии находятся в `licenses/` и включены в APK в `assets/licenses/`.

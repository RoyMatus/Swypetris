Политика конфиденциальности Swypetris

Дата обновления: 10 октября 2026 года. Приложение: Swypetris (ru.itoltec.swypetris). Разработчик: Roy Matus. Контакт по вопросам конфиденциальности: piligrim18@gmail.com.

Swypetris — бесплатная игра, в которую можно играть без интернета. В приложении нет рекламы, покупок, регистрации и собственной аналитики игровых действий. Технические данные сервисов обновления описаны ниже. Игра не передаёт разработчику результаты партий, настройки или имя игрока.

Для проверки обновлений приложение использует интернет. При запуске и по нажатию «Проверить обновления» оно обращается к RuStore, если установлено из этого магазина, либо к GitHub Releases для прямой установки APK. Эти сервисы получают обычные данные сетевого запроса, включая IP-адрес; их обработка определяется политиками соответствующих сервисов. Для обновлений из RuStore используется RuStore SDK 10.5.1, включающий модули analytics и metrics. При работе SDK могут обрабатываться технические сведения о приложении и SDK (идентификатор пакета и версии), идентификаторы SDK, время и результаты операций обновления. Эти сведения нужны RuStore для работы и диагностики сервиса; SDK может сохранять технические события локально до отправки. Их обработку регулирует политика RuStore: https://www.rustore.ru/help/legal/privacy-policy-users . Это не отправка разработчику имени игрока, рекордов или истории партий. При прямой установке APK Swypetris проверяет GitHub Releases; ветка RuStore SDK выбирается только для установки из RuStore. Проверка не обязательна для игры: при отсутствии сети можно продолжать играть. Игра сохраняет на устройстве время последней проверки и сведения об отложенном предложении обновления.

После первого явного согласия приложение автоматически загружает и устанавливает обновления только из главного меню после сохранения партии. Этот режим можно отключить в настройках; до согласия загрузка и установка запускаются вручную. APK обновления загружается из GitHub в закрытое хранилище приложения. Проверяются размер, контрольная сумма, версия и подпись; APK не передаётся разработчику. Для установки Android может запросить разрешение на установку из Swypetris и системное подтверждение. Отказ не мешает игре. Незавершённая загрузка удаляется, проверенный APK хранится до установки либо удаляется при следующем запуске после семи дней. Файлы обновления и сведения об установке не входят в системную резервную копию.

На устройстве сохраняются настройки, введённое по желанию имя игрока, рекорды и прежняя история партий: дата, сложность, очки, строки, уровень, длительность и число пройденных кругов. Локальное автосохранение содержит поле, фигуры и игровые таймеры для продолжения после закрытия приложения; оно не включается в системную резервную копию. Имя можно не указывать. Эти данные нужны для отображения личных результатов и восстановления настроек; они не публикуются в онлайн-таблицах.

Android может резервировать настройки и историю игры в системной облачной копии или переносить их на другое устройство, если соответствующая функция включена пользователем. Резервным копированием управляют Android, производитель устройства и выбранный пользователем сервис. Разработчик Swypetris не получает доступа к этим копиям. Управление копиями и их удаление выполняются в настройках соответствующего сервиса.

По вашему выбору игра может использовать изображение как фон игрового поля. Системный выбор файла предоставляет доступ только к выбранному изображению; разрешение на доступ ко всей фототеке не запрашивается. Игра сохраняет собственную уменьшенную копию в закрытом хранилище и параметры кадрирования. Изображение не отправляется разработчику или сетевым сервисам и не входит в системную резервную копию игры. При выборе файла из облачного провайдера его загрузкой управляет выбранный вами провайдер. Отключение фона сохраняет копию для повторного включения, сохранение нового фона удаляет предыдущую копию. Черновики находятся в локальном кеше; очистка данных или удаление игры удаляет и её копии изображений, не затрагивая исходные файлы.

После абсолютной победы вы можете создать открытку PNG с введённым именем и итоговыми очками. Файл создаётся на устройстве. Только при нажатии «Поделиться» Android предлагает выбрать другое приложение и предоставляет ему доступ на чтение к этой открытке. Swypetris не отправляет файл или имя автоматически; дальнейшую отправку и обработку выполняет выбранное вами приложение по своим правилам. Файлы открыток и кеш можно удалить очисткой данных Swypetris.

Разрешение на вибрацию используется только для игровых эффектов и проверки переключателя «Вибрация». Игра не запрашивает доступ к контактам, местоположению, камере, микрофону или рекламному идентификатору.

Кнопки связи открывают выбранные пользователем почтовое приложение, браузер или Telegram. Сообщение не отправляется автоматически. Дальнейшая обработка данных регулируется правилами соответствующего сервиса. Если вы сами пишете разработчику, предоставленные адрес и содержание обращения используются для ответа и решения вопроса; удалить переписку у разработчика можно запросом на указанный email.

Локальные данные хранятся до очистки данных приложения или его удаления. Для удаления откройте системные настройки Android → Приложения → Swypetris → Хранилище → Очистить данные. Это удалит результаты, настройки и автосохранение. При повторной установке Android может восстановить их из системной копии; при необходимости отдельно удалите такую копию.

Приложение не предлагает публиковать персональные данные других людей. Изменения обработки данных будут отражены в новой версии этой политики. Актуальный текст доступен внутри приложения на странице «Контакты» → «Конфиденциальность».
